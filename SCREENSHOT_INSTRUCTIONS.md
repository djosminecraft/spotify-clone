# 📸 Как добавить скриншот на GitHub

## Инструкция по загрузке скриншота:

### 1. Сохраните скриншот
- Сохраните ваш скриншот как `spotify-clone-screenshot.png`
- Размер: рекомендуется 1200x800 пикселей или больше
- Формат: PNG или JPG

### 2. Загрузите файл в репозиторий
Есть несколько способов:

#### Способ A: Через GitHub веб-интерфейс
1. Перейдите в ваш репозиторий: https://github.com/djosminecraft/spotify-clone
2. Нажмите "Add file" → "Upload files"
3. Перетащите файл `spotify-clone-screenshot.png` в папку `assets/images/`
4. Напишите коммит: "Add project screenshot"
5. Нажмите "Commit changes"

#### Способ B: Через Git команды
```bash
# Поместите файл в папку assets/images/
# Затем выполните:
git add assets/images/spotify-clone-screenshot.png
git commit -m "Add project screenshot"
git push origin main
```

### 3. Проверьте результат
После загрузки скриншот должен отображаться в README.md:
- В начале файла (после заголовка)
- В секции "Screenshots"

## Требования к изображению:
- ✅ Высокое качество (1200x800+ пикселей)
- ✅ Показывает главную страницу приложения
- ✅ Хорошо видно интерфейс и функциональность
- ✅ Формат PNG или JPG
- ✅ Размер файла не более 5MB

## Готово! 🎉
После загрузки ваш README будет выглядеть профессионально с красивым скриншотом!
